## 背景与范围

新增 `my-learn`，支持借助 AI 研究并学习此前不会的知识或技能。
将目标、知识联系、交互课程、练习表现和下一步安排连接起来，按实际证据逐步补齐短板。

- **本次范围**
  - 确认学习目标与起点，核对可信资料，建立带关系说明的知识依赖。
  - 生成可本地打开的 HTML 课程，按主题使用参数实验、简单动画与作答反馈。
  - 依据回答、提示依赖和实践表现调整练习，安排变式与延迟回忆。
  - 持久化当前学习档案，定义 HTML 结果导出与 Agent 读取规则，提供可运行示例。
  - 更新技能发现说明、UI、README 和实际受影响的插件描述。
- **非目标**
  - 不建设模型后端、账户、云同步或自动提醒服务，不把静态 HTML 说成在线 AI 导师。
  - 不自动安装本机技能、修改客户端配置、升级版本或发布。
  - 不搬移已有面试档案，不将一个学习主题或固定题型当作所有课程的模板。

## 验收标准

- **验收标准(AC-1)：入口与起点**
  - 当用户要求持续学习新技能或概念时，应选择 `my-learn`；一次答疑直接回答。
  - 应复用已知目标和档案，只澄清影响当前课程的缺口，按必要程度诊断前置基础。
  - 面试与刷题默认沿用 `my-interview`；用户明确使用通用课程方式时尊重其选择。
- **验收标准(AC-2)：资料与知识联系**
  - 应依据可信资料讲解，区分来源支持的事实、简化模型、推断和未核实内容。
  - 应说明知识间的前置、因果、对比或迁移关系，避免只列术语与无解释的连线。
  - 调研应服务当前学习目标，资料不可得时明确缺口，不无限收集后才开始教学。
- **验收标准(AC-3)：交互课程**
  - 应围绕当前可完成的小目标生成 HTML，按需要提供参数实验、分步动画和即时反馈。
  - 交互应能观察目标原理，示意模型应标明边界；键盘、移动端和减少动画偏好可用。
  - 本地 HTML 应直接可用，不默认要求构建工具、模型 API 或外部网络资源。
- **验收标准(AC-4)：动态练习与补缺**
  - 应依据实际表现选择解释、预测、操作、实现或迁移任务，不固定单一路线。
  - 应区分独立完成、提示完成、看过答案与迁移表现，避免一次答对就判定熟练。
  - 出错后应先定位知识、操作或迁移缺口，再补讲并使用不同问题验证；允许跳过或直接讲解。
- **验收标准(AC-5)：档案与跨会话**
  - 应沿用用户指定或已有学习目录，个人数据不写入技能安装目录。
  - 档案应记录目标、知识关系、表现依据、薄弱点和下一步，未知字段保持未知。
  - 重复读取同一作答结果不应累计为新证据；矛盾数据应保留并标记，避免覆盖旧结论。
  - 后续调用读取已有档案续学，不声称安装技能即可自动注入状态、执行复习或跨机器同步。
- **验收标准(AC-6)：HTML 与 Agent 衔接**
  - HTML 应能导出带版本、主题、课程、题目、尝试标识和提示记录的作答 JSON。
  - 应保留原始回答与判分依据；开放题只记录待评，不由空泛规则自动标为掌握。
  - Agent 应读取结果后分析和更新课程；未收到结果时不虚构学习行为。
  - 示例应真实记录答题和提示使用，支持重试、重置实验及 JSON 导出。
- **验收标准(AC-7)：接入与验证**
  - 技能源数据、引用及 UI 应可解析，默认提示显式包含 `$my-learn`。
  - README 与客户端描述应包含新技能，现有目录发现和状态栏排除规则继续生效。
  - 应区分结构检查、示例运行和独立教学效果验证；不将静态检查当作学习效果已证实。

## 关键设计

- **组织**：入口维护目标与流程；学习设计、档案规则和 HTML 课程细节分别按条件读取。
  HTML 示例是可改编的课程资产，主题队列不构成技能范围限制。
- **数据位置**：沿用已有工作区；缺省在当前项目约定的文档或学习区建立主题目录。
  默认仅维护一份当前档案，课程与纳入档案的原始结果或等价记录作为证据引用。
- **反馈分工**：HTML 处理已生成的实验、作答与反馈；Agent 负责研究、解释和生成后续课程。
  第一版以 JSON 导出并读取衔接，浏览器存储只可作为备份，不作为唯一档案。
- **影响范围**：新增技能指令、参考和 HTML 资产，更新发现文案；无业务 API、数据库或外部服务契约变更。
- **版本**：四份组件清单同步升级为 `2.0.5`；本机共享技能安装另行执行。

### 当前结果与边界

- **结构检查**：`quick_validate.py` 检查11个技能通过；新技能6个文件，UI 提示包含 `$my-learn`。
  5份 JSON 清单可解析，四个版本字段同步为 `2.0.5`；改动文档的相对引用与差异格式检查通过。
- **示例运行**：使用本机 Chrome 新无头模式实际打开本地 HTML。
  验证初始导出禁用、正确与错误作答、非法输入、逐轮实验与重置、参数变化和提示保留、
  过量处理及零值、绘制上限、开放题待评，以及真实 JSON 下载和重复导出标识稳定。
  6次测试作答的原始回答、上下文和判分结果一致；测试数据未写入个人学习档案。
- **使用检查**：320px 与390px 视口无横向溢出，减少动画时禁用动画；
  键盘可触发按钮和调整参数，先看实验后答题保留已见结果标记；无页面异常和外部资源请求。
  1280px 截图已人工查看；不据此声称所有浏览器和设备均已验证。
- **规则走查**：核对持续学习与一次答疑分流、已有目标复用、缺前置时补缺、提示后换例、
  开放题待评、重复结果去重和证据冲突处理，以及未返回结果时不虚构表现。
  以上是指令与协议检查，不是独立模型实际执行的证据。
- **验证限制**：当前环境未提供 `plugin-creator` 的专用校验器，未执行该检查。
  Pi 使用原生目录解析器检查；包筛选配置保持原值并核对集合，不等于已在所有客户端安装。
- **待回归**：新主题研究与课程生成、真实学员反馈、Agent 导入去重、跨会话读取和动态选题效果。
  浏览器示例通过不能证明学习成效，未进行独立 Agent 教学评估。
- **版本与安装**：源码完成并随 `2.0.5` 提交发布；本机共享目录尚未安装新技能，真实教学仍待回归。
