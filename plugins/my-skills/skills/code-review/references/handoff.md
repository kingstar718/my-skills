# 代码任务交接

用于跨会话或跨 Agent 继续同一代码任务；默认保持简短，只记录下一步需要的信息。

## 保存内容

- **目标与范围**：当前目标、已确认选择、明确不做的内容，以及仍有效的授权。
- **当前状态**：仓库、分支、关键提交、未提交改动及需要保留的用户修改。
- **依据入口**：规格、任务、研究结论和证据的路径或链接；正文已有的内容不再复制。
- **验证**：实际执行的检查与结果、适用版本或改动范围、尚未覆盖的环境和行为。
- **继续工作**：未决事项、真实阻塞和下一项可执行动作；相关技能只列当前可用且需要的入口。

优先使用用户指定或仓库已有交接位置；没有约定时保存到系统临时目录并报告绝对路径。
需要长期保留的决策仍回填原规格；临时文件不是永久知识库或自动加载的记忆。

## 完成检查

接手者应能找到实际改动、确认哪些检查已做，并区分可以继续与必须等待的事项。
移除密钥、认证头、个人数据和无关日志；保留定位问题所需的脱敏信息。
新会话或其他 harness 需要显式读取交接文件，不宣称写盘后已自动注入。
