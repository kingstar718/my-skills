# 前端验证

先读取项目已有组件测试、浏览器测试和构建配置，复用框架与定位方式。
以下按风险选择，不要求为每次样式调整新增测试。

| 风险 | 合适的证据 | 不能据此证明 |
| --- | --- | --- |
| 数据转换、格式化、状态计算 | 函数单测与独立样例 | 页面已正确渲染 |
| 点击、输入、选择及事件反馈 | 组件挂载后按角色、文本或标签交互 | 真实浏览器布局与第三方 SDK 行为 |
| 路由、存储、跨页面和完整用户路径 | 浏览器测试及明确的网络替身或隔离服务 | 未连接的真实服务可用 |
| 尺寸、滚动条、遮挡与视觉层级 | 真实浏览器观察、截图或布局断言 | 所有屏幕与设备均已覆盖 |

- 模拟网络或 SDK 时只保留目标所需契约；记录哪些行为没有真实执行。
- 等待可观察状态或请求完成，避免固定 sleep；检查失败、空数据、重复操作等相关分支。
- 断言从用户行为出发，不依赖组件私有状态、内部方法名或无关 DOM 层级。
- JSDOM 的事件或属性检查不能证明地图 SDK、CSS 布局或移动端 PWA 展示。
- 没有浏览器能力时，完成可行的代码与组件验证，并将实际展示列为待回归。
