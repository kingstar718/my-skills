# 交互课程

用于生成 HTML 教学、简单动画、参数实验或浏览器练习。
结果字段和读取规则以[学习档案](learning-state.md#作答结果协议)为准，避免另建一套协议。

## 一节课的内容

- **可完成目标**：说明本节要独立解释、预测或完成什么，联系当前目标与必要前置。
- **必要讲解**：保留当前任务需要的原理、可信来源和模型边界；参考链接指向对应资料。
- **知识联系**：说明该原理与已知概念如何相连，以及下一阶段会怎样使用。
- **可观察实验**：控制一个关键变量，展示过程和结果，让用户先预测、再操作、再解释差异。
- **反馈与练习**：客观题按明确规则反馈，开放题记录回答待评；提供提示、重试和结果导出。

不机械为每节课加入所有控件；文字或静态图已经能解释清楚时保持简单。
动画应表现状态变化或因果过程，不用装饰运动代替讲解。

## 页面与实验

- **直接使用**：默认输出自包含 HTML，内联必要的 CSS、JavaScript 与 SVG，支持本地打开。
  阅读资料可链接外部网页，核心课程不依赖 CDN、在线字体、模型 API 或构建工具。
- **交互控制**：提供单步或可控播放、重置与参数说明，区分重置实验和清除作答。
  新参数改变题目预期时保存作答时的上下文，避免按当前控件值重判旧答案。
- **数学与示意**：公式、单位和状态更新顺序保持一致；标出简化假设与不能推导的实际结论。
  示意动画不能用作真实系统性能或用户操作成功的证明。
- **使用体验**：移动端可读，控件有标签且可键盘操作；状态变化有文字反馈。
  支持暂停和减少动画偏好，颜色之外还用文字或形状区分状态。
- **答案处理**：收集作答后才在界面揭示解释，不自动提交或代答。
  本地 HTML 不能隐藏源码中的答案；有认证要求时另行设计可信评测，不宣称防作弊。

## 结果与下一课

1. **记录尝试**
   - 每次实际提交记录原始回答、题目标识、参数、提示与反馈暴露情况。
   - 使用提示或看答案后不要通过刷新题目、重置实验将该题恢复为未见答案。
     换题或变式可以重新验证，但旧尝试继续保留。
   - 输入无效时说明约束，不把空值静默换成正确答案；开放题标为待评。
2. **导出结果**
   - 使用下载按钮导出 JSON，并说明把结果文件交给 Agent 后才能调整课程。
   - 不默认上传数据；浏览器存储可用作备份，但 `file://`、浏览器隔离和隐私模式可能限制它。
     导出文件是跨会话交接的主要方式，不声称页面能直接修改本地档案。
3. **安排后续**
   - Agent 读取结果，判断是否需要补前置、减提示或增加场景变化，再更新档案和下一课。
   - 网页内预先编写的分支题只能覆盖已生成内容，不等于实时调用模型生成无限新题。
   - 用户希望网页内持续与 AI 对话时，再评估已有连接或模型服务；不在第一版静态课中伪造该能力。

## 可运行示例

需要从最小课程起步时，参考[队列课程示例](../assets/queue-lesson.html)。
它包含一个离散队列模型、预测题、开放解释题和版本化作答导出，可本地直接打开。

- 改编时替换目标、知识关系、实验与判分依据，并更新主题、课程、修订和题目标识。
- 示例的数值与题型只用于演示数据衔接，不要求所有领域使用队列、数值题或同样布局。
- 默认保持单文件；已有课程组件且确需共享时可复用，不为第一节课预建组件系统。

## 验证范围

- 对有独立预期的例子核对实验状态与反馈，至少包括初始、一次操作、重置和边界情况。
- 实际验证提示后提交、看反馈后重试、开放题待评，以及导出字段与题目上下文一致。
- 有浏览器工具时检查真实交互、导出、窄屏和减少动画；仅检查脚本或 HTML 结构时说明未验证的展示行为。
- 课程运行通过只证明示例程序的相应行为；不把 Agent 自测写入用户档案，也不声称教学效果已验证。
